## What Opslane is

Opslane watches errors and session recordings from your app and turns them into a short list of issues. It picks the issues worth fixing and investigates them against your repository. A fix that builds and passes your tests in a sandbox opens as a pull request. When it can't fix something, it says why. A daily digest keeps you out of the dashboard.

## Where to start

Setting it up: the [self-host quickstart](/quickstart/self-host/) runs the stack with Docker Compose, then the [install guide](/install/) adds the SDK to your app and [connecting GitHub](/guides/github-app/) unlocks pull requests.

Evaluating it: the [architecture overview](/architecture/overview/) shows the pieces and the trust boundaries, [life of an error](/architecture/life-of-an-error/) follows one error through the pipeline, and [trust and security](/architecture/trust/) lists exactly what leaves your host.

## How the docs are organized

**Start here** covers setup: self-hosting the stack and installing the SDK. **Guides** each cover one task, from uploading source maps to Slack notifications. **Architecture** explains the system for someone deciding whether to trust it. **Reference** tables (SDK options, HTTP routes, environment variables, reason codes) are checked against source on every CI run. **Contracts** are the promises that hold across versions.

## What Opslane is not

- **Not an APM or metrics backend.** Opslane ingests application errors and the session context around them: breadcrumbs, network timing, and optional replays. It does not do latency percentiles, distributed tracing, or infrastructure monitoring.
- **Not autopilot.** Opslane opens pull requests but never merges them. Review and merge stay with the repository owner.
- **Not a dashboard to babysit.** Conclusions ship as PRs and issues; the dashboard exists for replays and settings, not triage duty.
- **Pre-1.0.** The [`POST /api/v1/events` wire contract](/contracts/events/) is append-only and backward-compatible. Other interfaces may still change before 1.0.
